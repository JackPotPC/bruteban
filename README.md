# bruteban

**bruteban** — это утилита для обнаружения и автоматической блокировки попыток brute-force атак по логам сервисов (SSH, веб-серверы и др.).

## Установка

### Требования

* Linux
* Python 3.10+
* Доступ к firewall

### Клонирование репозитория

```bash
git clone https://github.com/username/bruteban.git
cd bruteban
```

### Запуск скрипта установки

```bash
sudo bash install.sh
```
